Scope
Inert evidence store. No store is constructed by the daemon and no runtime
consumer reads evidence authority. No stream, wire-format, routing, discovery,
binding-registry, send, trust or receive-authority behavior was switched over.
The existing verified ingest paths retain bounded, TTL-only verbatim source
bytes for future S2 pairing. Evidence config validates 1..=7 days (default 7).
The input .adr0089-impl-plan.md remains untracked and unchanged.

Public API
EvidenceConfig { max_age_days }, validate().
EvidenceRecordV1 { announcement, advert, certificate, relation, stored_at_ms },
  verify(now_ms, max_age_ms).
EvidenceFileV1 { records, watermarks }, encode()/decode(); MoveWatermarkV1.
EvidenceView: verified announcement, advert (registry unknown), optional cert.
PeerEvidenceStore::open(data_dir, config, Arc<dyn EvidencePolicy>, now_ms).
  usable(agent, machine, now_ms) -> Option<EvidenceView> is the sole authority.
  ingest(record, Gossip|Hello, now_ms), ingest_move_advert(bytes,key,now_ms),
  live(agent,now_ms), remove_where(predicate), maintain(now_ms),
  flush(now_ms, shutdown), counters(), is_memory_only().
EvidencePolicy supplies current relationship and all revocation decisions;
  it is called on every use and must not re-enter the store.
RelationshipInputs/relationship_set resolve current enrollments, grants and
  active shared-group rosters, with verified records for machine/user mapping.
VerifiedWireCapture::get returns original bytes; S1 has no runtime reader.
S2 must wire current policy, startup load, periodic maintenance/flush and
  shutdown flush. It must never copy authority into another cache.

ADR-author questions / interpretations for review
1. The plan's 30-day store/config bullets conflict with Accepted ADR section 3.
   This implementation follows the Accepted default 7, min 1, max 7. Please
   correct the plan, not the immutable Accepted ADR.
2. W/L age-check announcement and advert timestamps independently. Certificates
   retain their existing signed issuance/future-skew and expiry rules; their
   issuance date is NOT treated as a 15-minute heartbeat. Requiring newly issued
   owner certificates for every Hello would invalidate normal long-lived certs.
   Certificate bytes use AgentCertificate's existing storage encoding, checked
   for exact canonical consumption; all original supplied bytes are retained.
   Please confirm this resolves the plan's ambiguous 'each part' wording.
3. An unreadable store is permanently memory-only. Complete fresh initial
   records may be used in memory, but a move cannot meet the durability rule:
   it fails closed and stays suspended, with evidence_move_write_failed counted.
   Please confirm this combined interpretation of sections 3 and 8.
4. Time out of the relationship set is tracked in memory by maintain(); after
   restart absent watermark agents tie at first observation, with agent-ID tie
   breaking. V1 persists only (t,M), as specified. Exact pre-restart absence
   ordering would need another versioned field; confirm conservative ties.
